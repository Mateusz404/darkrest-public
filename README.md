# darkrest-public

A simple farewell page for Darkrest.Online. Plain HTML and CSS, with no dependencies or build step.

## Preview

Open `index.html` directly, or run `python -m http.server 8080` in this folder and visit http://localhost:8080.

## Discord invite

The Discord button links to https://discord.com/invite/WBMSR4qAzF. Update its `href` in `index.html` if the invite changes.

## Hosting

Serve this folder with any static hosting service. Keep `index.html`, `styles.css`, and `assets/` together.

The animated logo is replaced with a still image when a visitor prefers reduced motion.
